# 智慧导师前端视觉改造 · Claude Code 指令包

> 用途：指挥 Claude Code 分步改造智慧导师多智能体系统前端，从"普通"升级为"审查人认可的高级视觉感"。
> 使用方法：按顺序把「公共上下文」+ 每条指令依次发给 Claude Code，一次完成一条，跑完 git commit 后再进入下一条。

---

## 0. 设计诊断与总方针

**评审说"太普通"的三个真相**（不是颜色问题）：

1. 视觉密度均匀 —— 左中右三栏权重相同，眼睛不知道该看哪里。
2. 右栏是"静态配置面板" —— 承载不了"某个 agent 是本轮重点"的动态语义。
3. "智慧导师"的产品人格在视觉上完全缺席 —— 看起来只是通用 chatbot + 通用 agent 面板。

**总方针**：

- 对话框是产品骨架，任何改动不牺牲对话可用性。
- 展示性 **寄生在** 产品结构外围（左栏轨迹缩略图 / 中栏顶部路径条 / 中栏底部 Interaction Log / 右栏 Agent Studio / 认知地图抽屉）。
- "本轮重点 agent" 在三处形成视觉互相印证：右栏 Hero Slot、中栏路径条金色节点、左栏会话缩略图金光点。
- 色调走双主题（Dark / Light），唯一强调色是"暖金"。
- 高级感靠 **材质 / 字体 / 微观精致度** 三层，不靠彩色。参照物：Linear、Arc、Things 3、Vercel Dashboard、Stripe Docs。

---

## 1. 最终设计规范（每条指令的公共基线）

**布局**：三栏保留、左右可折叠。折叠态与现状一致；展开态是新增信息密度的空间。

**中栏**（对话主区）：
- 对话框位置/大小/交互完全不动。
- 顶部新增 32px 高的 Cognitive Path Bar（本轮触及的知识节点横向串联，主 agent 触及的节点金色发光）。
- 底部现有"思考过程"面板重构为 Agent Interaction Log（agent 交接可视化为流线，重点 agent 输出块加渐变描边 + "本轮重点"徽章）。

**左栏**（展开时）：会话列表从"新对话"文本，升级为 mini 学习轨迹缩略图（4-8 个小圆点串成一条线，重点节点金色高亮）+ 会话主题短语。

**右栏**（展开时，Agent Studio）：垂直三段
- Hero Slot（40%）：本轮 1-2 个重点 agent，卡片有呼吸光晕、"本轮重点"徽章、渐变描边。
- Ensemble Rail（40%）：其他被调用 agent 的横向紧凑卡带，hover 展开完整参数。
- Trace Timeline（20%）：本轮 agent 调用顺序竖向时间线，可点击回溯。

**知识图谱抽屉**：右下角悬浮按钮"认知地图"，点击展开全屏浮层。

**色调**：
- Dark：`#0B0E14` 底 + `#F5F5F7` 字 + `#D4A24C`（暖金）唯一强调色。
- Light：`#FAFAF7` 底 + `#1A1D24` 字 + `#B8862F` 暖金。
- 禁彩色渐变、禁两种以上强调色。

**动效原则**：慢、低饱和度、只在信息变化处发生。禁 3D 变换、禁彩色阴影、禁镜面反射。

## 3. 指令 0：视觉气质公约（Visual DNA）

> **必须最先执行**。此公约是后续所有任务的硬基线。

```
# 任务 0：视觉气质公约（Visual DNA）

## 目标
在动手做任何组件前，先建立整站的视觉基调。任何后续任务必须遵守本公约。
参考产品的气质：Linear / Arc / Things 3 / Vercel Dashboard。
反面参考（禁止像）：SaaS 后台模板、Bootstrap 默认、任何有彩色渐变的仪表盘。

## 输出契约

### 1. 字体系统（在 index.html 或全局样式引入）
- Display 字体：Inter Display（或 IBM Plex Sans）用于标题、Hero Slot 名称、数字大字
- Body 字体：Inter 400/500 用于正文
- Mono 字体：JetBrains Mono 或 IBM Plex Mono 用于时间戳、参数值、agent id
- 全局设置 font-feature-settings: 'ss01', 'cv11'（Inter 样式集）
- 所有数字加 font-variant-numeric: tabular-nums
- 字号阶梯：11 / 12 / 14 / 16 / 18 / 24 / 32，禁止非阶梯值
- 字重阶梯：400 / 500 / 600 / 700，禁止 300 和 800+
- 字距：body 用 -0.01em，caption 用 0.01em，24px+ 标题用 -0.02em

### 2. 材质层（关键！CC 常忘）
- 建一个 SVG noise texture（filter feTurbulence baseFrequency 0.9），转成 base64 data URL
- 全站 body 加一层 ::before 伪元素，background 是该 noise
- opacity：Dark 主题 0.04 / Light 主题 0.025
- pointer-events: none，不影响交互
- 结果应该是：眼睛几乎察觉不到，但对比"关掉这一层"能明显感到质感差异

### 3. 分隔线规范
- 所有 border 用 0.5px（Retina 屏下 = 1 物理像素）
- 颜色用 --color-border-subtle
- 分隔线两端留 16px 内边距，不允许贴边

### 4. 层级阴影 Token（写入 tokens.css）
- --elevation-1: none（仅靠背景色差异）
- --elevation-2: 0 1px 2px rgba(0,0,0,0.06), inset 0 1px 0 rgba(255,255,255,0.04)
- --elevation-3: 0 8px 24px -8px rgba(0,0,0,0.15), inset 0 1px 0 rgba(255,255,255,0.06)
- --elevation-4: 0 24px 48px -12px rgba(0,0,0,0.25), inset 0 1px 0 rgba(255,255,255,0.08)
- Light 主题下阴影 rgba 数值不变，仅色相换为 rgba(20,20,20,...)

### 5. 动效曲线 Token
- --ease-out: cubic-bezier(0.22, 1, 0.36, 1)（默认离场）
- --ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1)（打开、展开）
- --ease-standard: cubic-bezier(0.4, 0, 0.2, 1)（常规过渡）
- 时长阶梯：120 / 200 / 320 / 480 / 800ms，禁止其他值

### 6. 图标系统
- 全站只使用 Lucide React（如未安装则 npm install lucide-react）
- 尺寸只用 16 / 20 / 24 三档
- strokeWidth 全部设 1.5
- 禁止 emoji 作为 UI 图标（emoji 仅允许出现在用户消息文本里）
- 徽章"⚡ 本轮重点"改为 <Sparkles size={14} strokeWidth={1.5} /> + 文字"本轮重点"

### 7. 光的方向性
- 所有 elevation-2 及以上的卡片，顶部必须有 1px inset 高光
- 呼吸光晕改为上柔下重的椭圆：box-shadow 使用两组
  - 上：偏移小、模糊大、透明度高
  - 下：偏移大、模糊小、透明度低

## 硬约束
- 禁止引入除 Inter / IBM Plex / JetBrains Mono 之外的字体
- 禁止使用 3D transform / 玻璃拟态（frosted glass 仅限抽屉背景 backdrop-blur）
- 禁止使用彩色阴影（如 shadow 里带 accent 色）
- 禁止圆角 > 12px，也禁止圆角 = 0（选择 6/8/10/12 四档）

## 验收 DoD
1. 关掉 noise texture 层截图对比：眼睛可感知到"有质感 vs 塑料感"差异
2. Devtools 检查所有卡片：能看到顶部 1px 高光和方向性阴影
3. 打开右栏切换 agent：过渡使用 spring 曲线，动作有轻微 overshoot
4. 全站 grep 检查：无 emoji 作为 UI 元素、无非阶梯字号、无 1px 边框（Retina 下应全为 0.5px）
```

## 10. 指令 7：动效收敛与最终验收

```
# 任务 7：动效统一化与最终验收

## 目标
把前 6 步中散落的动效收敛到一套 keyframes 定义，防止未来漂移；并做全局验收。

## 输出契约
在 styles/animations.css 集中定义：
- @keyframes breathe（透明度 0.4→0.8→0.4，--duration-breath 循环）
- @keyframes ripple（scale 0→1, opacity 1→0，--duration-ripple 一次）
- @keyframes flow（沿路径粒子移动，--duration-flow 一次）

前面任务中用到呼吸/涟漪/流线效果的位置，改为引用这些 keyframes，
```

## 11. 使用建议与纠偏话术

**发送顺序**：公共上下文 → CC 摸清结构确认 → 指令 0 → 指令 1 → ... → 指令 7。

- "违反硬约束：禁止彩色渐变、禁止两种以上强调色。重新做 X 任务，只用 --color-accent。"
- "违反硬约束：使用了非阶梯字号 / 非阶梯圆角 / 非阶梯字重。重做。"
- "视觉参照物是 Linear / Arc / Things 3，不是 SaaS 后台模板。重新审视这一版是否偏离参照物。"

## 12. 视觉气质核对表（Review Checklist）

改完之后，用这份清单自查是否达到"高级视觉感"：

- [ ] 底部有肉眼几乎不可见的 noise 材质层，关掉后能感觉到差异
- [ ] 所有分隔线是 0.5px（不是 1px）
- [ ] 所有卡片顶部有 1px inset 高光（光从上来的物理直觉）
- [ ] 数字全部用等宽 Mono 字体、tabular-nums
- [ ] 打开 / 展开动效用 spring 曲线，有轻微 overshoot
- [ ] 全站没有 emoji 作为 UI 图标（都换成 Lucide）
- [ ] 全站没有彩色渐变，只有一枚暖金强调色
- [ ] 圆角只在 6/8/10/12 四档中选择
- [ ] 字号只在 11/12/14/16/18/24/32 阶梯中选择
- [ ] 阴影是黑色的（不是 accent 色的）
- [ ] 呼吸光晕是上柔下重椭圆（不是全方向发散）
