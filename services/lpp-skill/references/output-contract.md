## 适用条件

仅在运行时满足以下条件时生成完整输出：

- `status` 等于 `ok`；
- `message` 等于 `recommendations_ready`；
- `recommendation.questions` 恰有 5 道题；
- `order` 连续为 1～5；
- 每道题均提供题干、题型和知识点。

唯一的主推荐题来源是 `recommendation.questions`。不得增加、替换、删除或重排。

## 最终结构

固定输出三个部分：

1. 自然语言描述；
2. 推荐题表格；
3. 原始 JSON。

## 第一部分：自然语言描述

使用专业、简洁、可执行的教师口吻，控制在约 600～900 个汉字。不要机械复述字段，
而要解释路径为什么这样安排。

按以下顺序组织：

1. 说明学生、目标题、总体目标和 P1～P5 完成顺序。
2. 按连续出现的知识点对 5 道题分组，概括每组承担的教学作用。
3. 解释 P1～P5 各自要检查、建立或巩固什么，以及为什么放在当前位置。
4. 说明题目之间真实存在的递进：
   - 可依据题干、题型和顺序解释“识记→判断”“识别→表达”等功能变化；
   - 不把 `order` 或 `difficulty` 自动解释成难度递增；
   - 知识点、年级或主题发生切换且没有可靠关系时，明确说明是主题切换或独立练习。
5. 区分与目标题的直接关联和间接关联。同一知识点不等于完全覆盖目标题要求。
6. 概率字段存在时，可换算为百分比和百分点，但必须说明是模型预测，不保证实际提升。

只描述数据支持的教学作用。使用“用于检查”“帮助建立”“为后续练习提供基础”等
中性表述，不预设学生已经存在某种错误或能力缺陷。

不得出现：

- 内部算法、候选池、ACE 排名、诊断参数或搜索过程；
- 未提供的学生错误原因、作答习惯、学习行为或掌握结论；
- 对学习效果的保证；
- 第二套推荐题。

## 第二部分：推荐题表格

表格一题一行，共 5 行，严格按 `order` 映射为 P1～P5。固定列为：

| 列名 | 输出规则 |
| --- | --- |
| 规划优先级 | 使用 P1、P2、P3、P4、P5；只表示完成顺序，不表示置信度。 |
| 推荐题目 | 展示辅助题号、完整题干、题型、全部知识点和选项状态。 |
| 知识点描述 | 使用运行时知识点名称和目录描述，不自行扩写课程事实。 |
| 当前规划的目的&作用 | 结合题干、题型、所在顺序和目标题，说明该题要解决的问题及衔接作用。 |
| 当前知识点的前后序知识点 | 使用“前序 → 当前 → 后序”；无相邻知识点时写“无”。 |
| 潜在关联资源 | 展示运行时 `related_questions` 中的题号、完整题干、题型、难度；为空时写“暂无可用关联练习”。 |

“推荐题目”单元格采用以下结构：

```text
题号：{question_id}
完整题干：{question_text}
题型：{question_type}
知识点：{knowledge_point_names}
选项：{options 或“题库暂未提供选项”}
```

“当前知识点的前后序知识点”只使用运行时 `knowledge_sequences`。前序或后序为
`null` 时显示“无”，不得从常识推测。

“潜在关联资源”只展示运行时返回的关联题。若关联题同时属于 P1～P5，标注其主路径
优先级，并说明按原优先级完成、不重复安排。

表格中的“目的&作用”应与第一部分一致，但保持一至两句话，不复制整段自然语言说明。

## 第三部分：原始 JSON

在一个 `json` 代码块中原样输出本次规划所使用的运行时 stdout JSON 对象。

必须：

- 保留原有顶层字段、嵌套结构、字段顺序、数组顺序、数值精度、`null` 和空数组；
- 保留 `recommendation.questions` 的原始 5 道题及 `order`；
- 仅去除 JSON 对象之外的终端命令、shell 提示符或日志文本。

不得：

- 重新设计 JSON schema；
- 新增 `summary`、解释文字或表格派生字段；
- 删除、重命名、翻译或重排字段；
- 把自然语言说明写入 JSON；
- 估算或补造缺失值。

## 数据与降级规则

- `options` 为空：表格写“题库暂未提供选项”，JSON 保持 `[]`。
- 前序或后序为空：表格写“无”，JSON 保持 `null`。
- `related_questions` 为空：表格写“暂无可用关联练习”，JSON 保持 `[]`。
- 概率字段缺失：自然语言不补造概率说明，JSON 保持原状。
- 表格内容与原始 JSON 冲突时，以运行时原始 JSON 为准并停止生成，报告数据契约错误。
