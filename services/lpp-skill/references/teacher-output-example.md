## 示例用途

本示例只约束输出的结构、语气、长度和详略程度。不得复用示例中的学生、题目、知识点、
年级、难度或概率数据。处理真实任务时，始终以当次运行时 JSON 为准。

## 示例输入摘要

- 学生：23
- 目标题：题号 460，“生命系统能够维持稳定并持续发展，主要是因为它是一个开放系统，
  能够与外界进行什么类型的交换？”
- 目标题知识点：生命系统层次性
- 基线预测正确率：0.49888134002685547
- 规划后预测正确率：0.7210140824317932
- P1：题号 461，生命系统层次结构填空题，知识点“生命系统层次性”
- P2：题号 462，生命系统层次性判断题，知识点“生命系统层次性”
- P3：题号 115，物体位置单选题，知识点“位置与方向描述”
- P4：题号 116，物体位置填空题，知识点“位置与方向描述”
- P5：题号 117，东、西方向判断题，知识点“位置与方向描述”
- “生命系统层次性”前序为“生物圈”，后序为空。
- “位置与方向描述”前序为空，后序为“推力与拉力”。
- 每道题的关联题均由运行时提供，其中可能关联到另一道主推荐题。
- 所有题目的 `options` 均为空数组。

## 第一部分：自然语言描述

本次学习路径面向学生 **23**，以目标题 **460「生命系统能够维持稳定并持续发展，
主要是因为它是一个开放系统，能够与外界进行什么类型的交换？」** 为参照，建议按照
**P1 → P2 → P3 → P4 → P5** 的顺序完成5道练习。整组题主要覆盖“生命系统层次性”
和“位置与方向描述”两个知识点。

P1、P2与目标题同属“生命系统层次性”。P1要求补全生命系统从简单到复杂的结构层级，
用于帮助学生梳理细胞、组织、器官和器官系统之间的关系，先建立清晰的结构框架。P2
进一步通过判断题检查学生能否认识到生命系统具有明显的层次性，使练习从具体的层级
识记过渡到抽象的概念判断。因此，P1到P2形成了“结构组织 → 特征辨析”的递进。

这两道题能够为理解生命系统的整体特征提供基础，但目标题具体考查生命系统与外界进行
的交换类型，P1、P2并未直接覆盖这一内容。因此，它们更适合作为目标题的概念准备和
基础巩固，不能视为已经完整练习了目标题要求。

P3至P5转入“位置与方向描述”。P3从书包与课桌的位置关系入手，练习识别相对方位词；
P4要求根据大树这一参照物主动填写位置，作答方式由识别过渡到表达；P5进一步扩展到
东、西方向的判断。三道题形成了“相对位置识别 → 参照物下的位置表达 → 基本方向判断”
的练习序列。

“生命系统层次性”与“位置与方向描述”之间没有本次数据能够证明的直接前后序关系，
因此P2到P3应理解为练习主题的切换，而不是知识上的自然递进。教师可将P1、P2视为与
目标题直接相关的基础练习，将P3至P5视为另一组扩展练习，并分别观察学生在两个知识点
下的表现。

运行时预测学生对目标题的正确率由约 **49.89%** 变为 **72.10%**，预测提升约
**22.21个百分点**。该结果仅用于辅助教师安排练习，不代表学生完成练习后一定达到
相同提升；后续仍需结合学生的实际作答情况判断是否需要补充讲解或调整练习。

## 第三部分：原始 JSON

本示例不重复粘贴 JSON。实际输出时，必须按照输出契约的第三部分规则，将当次运行时
stdout 中的单个 JSON 对象原样放入 `json` 代码块；不得把本示例的任何数据写入真实
任务 JSON。
