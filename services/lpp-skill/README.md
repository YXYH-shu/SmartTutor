# lpp-skill

`lpp-skill` 是一个学习路径规划技能：给定学生历史做题记录和一个起始题目，
从该题在学生序列中的最后一次出现位置开始向后寻找规划目标，再用 DSMOEA 风格的
双策略多目标遗传算法搜索一段短练习序列。

## 当前项目口径

- 搜索核心仍然是题目级序列搜索。
- 知识点用于构造候选池、指导变异，以及汇总输出知识点路径。
- 生产后端默认使用 `kt-runtime-skill` 的 REKT 模型和数据。

## 当前输出策略

遗传算法本身优化的是“尽量少做题也能提升目标题正确率”，因此 GA 原始输出
可能少于 5 题。

为了满足产品侧“固定推荐 5 道题”的要求，命令行入口会将搜索结果组织为 5 道
不同的练习题，但**不改动 GA 本体**。选题顺序如下：

1. 保留 GA 原始顺序，并先做去重。
2. 若不足 5 题，优先补入与目标题同知识点的题目。
3. 若还不足 5 题，再补入 ACE 经验矩阵里高价值知识点对应的题目。
4. 若仍不足 5 题，最后从更宽的候选池兜底。

补齐时遵守这些约束：

- 最终尽量输出 5 道不同题目。
- 不把目标题本身放回推荐列表。
- 优先不重复推荐历史窗口里已经出现过的原题；只有候选不足时才放宽。
- 对学生始终只展示一组按顺序完成的 5 道题，不展示内部选题过程。
- 每道推荐题都展示题干、知识点和题型，题号只作辅助标识。

## 运行

```bash
cd services/lpp-skill
REKT_DEVICE=cpu REKT_ALLOW_CPU_FALLBACK=1 \
conda run -n kt python scripts/run_lpp.py --student-id 43
```

命令行会向 stdout 输出一个 JSON 对象。学生侧的老师口吻说明应由调用 Agent 基于
`recommendation.questions` 生成，而不是由运行时直接打印。

`--target-question-id` 会从学生做题序列末尾向前定位该题最后一次出现的位置；程序用
该题前最多 10 道题预测该题。若预测正确率不低于 0.5，目标会依次移动到下一题并
重新预测；若已到序列最后一道题，则仍会强制执行规划并输出 5 道题。
