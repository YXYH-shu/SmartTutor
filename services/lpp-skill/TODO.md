# LPP Agent 输出改造 TODO

## 目标

将学习路径规划 Agent 的最终回复统一为三部分，便于教师快速理解规划意图、查看推荐题目，并让下游系统消费结构化结果：

1. 自然语言描述
2. 推荐题目表格
3. JSON

运行时 `scripts/run_lpp.py` 仍保持“stdout 只输出一个 JSON 对象”的既有契约；以下内容由读取运行时 JSON 的 Agent 负责组装，不在运行时混入教师口吻或 Markdown。

## 待办

- [x] 定义 Agent 最终回复的固定章节与字段映射。
  - 自然语言描述：用教师口吻概括本次规划的优先级、主要补强知识点、练习目的，以及完成后的预期作用。
  - 推荐题目表格：展示 5 道题，严格使用 `recommendation.questions` 的 `order` 顺序；每行必须保留完整题干、知识点和题型，不得只给题号。
  - JSON：原样透传运行时 stdout 中的单个 JSON 对象，不重组 schema，不写入自然语言。

- [x] 定义推荐题目表格字段。

  | 字段 | 说明 | 数据来源/生成规则 |

  | 规划优先级 | 该题在当前路径中的练习优先程度 | 由 `order` 生成，如“P1（优先完成）”至“P5”；不得伪装成模型置信度。 |
  | 知识点描述 | 该题涉及的知识点及面向教师的简要说明 | `knowledge_points` 中的名称和描述。 |

  | 潜在的关联资源 | 同一知识点下的另一道练习题 | 使用 `exercise_info.json`；排除当前题与目标题，允许关联到另一道主推荐题。 |

## 验收标准

- Agent 回复同时具备自然语言、表格和 JSON 三种表达，三者题目顺序和知识点一致。
- 表格的五项要素全部出现，且知识点顺序和关联练习题均有明确的数据来源或缺失标记。
- 推荐题目始终为运行时返回的同一组、同一顺序的 5 道题；不额外推荐候选题。
- 未接入图谱或资源服务时，基础学习路径规划仍可正常交付。
